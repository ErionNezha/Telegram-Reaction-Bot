# Telegram Reaction Bot

Userbot Telegram që vendos reagime automatike në mesazhe (pyrogram) — versionet 2x dhe 3x.

`Python` `pyrogram` `Telegram`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Telegram-Reaction-Bot/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Vendos API_ID/API_HASH, `pip install pyrogram`, pastaj `python main_3x.py`.
